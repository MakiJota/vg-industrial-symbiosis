How the estimates are made

The same core pipeline is applied to Västra Götaland and Skaraborg so that their results can be compared. The county run covers 49 kommuner and four sub-regions. All quantities refer to 2022 unless otherwise noted.

  1. Describe the regional economy. SCB workplace employment is grouped by kommun and industry. Trade data are used to estimate production inputs imported by businesses in sectors A–F, allocated to local workplaces using employment.
  2. Estimate waste. Employment is multiplied by sector-specific waste intensities estimated from Eurostat waste and employment statistics. Estimated waste is distributed across European List of Waste codes using industry profiles.
  3. Identify possible substitutes. Waste codes are matched to four-digit imported products using documented exchanges in MAESTRI and the reviewed W2RKG knowledge graph. Implausible matches are excluded in applicable scenarios.
  4. Allocate compatible waste to demand. The model compares the amount and type of available waste with compatible input demand. It reports a regional optimum, kommun-level allocation (local matches first, then between kommuner), sub-region results, and anonymised firm-level estimates.
  5. Estimate value and compare scenarios. Allocated tonnes are valued at estimated regional import unit prices. Scenarios vary the matching sources and assumptions; the “without mineral fuels” scenario excludes CN 27, primarily crude oil, from demand.

Interpret with care

  • Import records omit goods bought from suppliers elsewhere in Sweden, so import demand is not total demand.
  • The mass-based substitution assumes one tonne of waste replaces one tonne of product; processing losses and technical constraints may make that unrealistic.
  • Waste intensities, especially quarry waste, and the matching database are uncertain. Different plausible assumptions produce materially different totals.
  • The allocation rules rank compatible exchanges; they do not model prices, contracts, logistics, quality approvals, or whether firms would actually trade.
